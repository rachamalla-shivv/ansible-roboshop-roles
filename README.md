# Ansible Roboshop Roles

Ansible automation for configuring Roboshop services using reusable roles.

## Structure
```text
group_vars/
include-import/tasks/
roles/
01-ec2-r53.yaml
inventory.ini
main.yaml
```

## Technologies
- Ansible
- YAML
- Jinja2
- Ansible Roles
- Inventory management
- Group variables

## Learning Outcome
Demonstrates moving from direct playbooks toward reusable role-based configuration management for Roboshop.
